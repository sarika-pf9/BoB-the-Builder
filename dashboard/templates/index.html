Latest qcow2 (scriptable)

Always serves the most recently-built qcow2 - ready as soon as the disk image itself is done, even if that build is still pushing component images to quay.io in the background. No build id needed, so it's stable to hardcode in a script or CI job: 

wget {{ latest_download_url }} -O vjailbreak-image.qcow2

qcow2 files aren't kept forever — any image older than {{ qcow2_retention_hours }} hours is deleted automatically to free disk space, whether or not a newer build has happened since (checked periodically in the background, not just when a new build finishes). Up to {{ keep_last_n_qcow2 }} are also kept as a safety margin regardless of age, in case a burst of builds lands inside one retention window. Grab the one you need before it ages out.

Component builds (controller/ui/sdk/ai) don't have a download link here — they're pushed straight to quay.io instead. Swap <tag> for the branch you built (there's no latest tag, every image is tagged with its branch name):
